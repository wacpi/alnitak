# PGC 前端（创建 / 上传 / 编辑 / 发布）设计方案

## 一、现状

- **服务端**：已具备完整 PGC 能力（见 [PGC_README.md](./PGC_README.md)）。
  - 类型：国创(CN)(1)、日创(JP)(2)、纪录片(3)、电影(4)、电视剧(5)。
  - 内容表 `pgc_content`：标题、封面、简介、年份、地区、评分、连载、集数、审核状态等。
  - 剧集表 `pgc_episode`：集序、标题、关联视频 ID(vid)、时长、发布时间等。
  - 接口：创建/更新/删除 PGC、添加/删除剧集、列表/详情/搜索/按类型/连载/推荐等。
  - 鉴权：创建/更新/删除/剧集增删 需登录且具备 PGC 权限（`RequirePGC()`）。

- **前端**：暂无。需要补齐「后台管理」侧的创建、编辑、发布与「C 端」侧的展示（后续可用 Flutter 或 H5）。

---

## 二、角色与能力

| 角色       | 能力说明 |
|------------|----------|
| 运营/管理员 | 拥有 PGC 权限：创建 PGC、编辑元信息、添加/删除剧集、删除 PGC。当前实现为「创建即审核通过」；若后续接入审核流，可增加「提交审核」「上/下架」等。 |
| 普通用户   | 仅可查看：列表、详情、剧集列表、搜索、按类型浏览、连载、推荐。 |

---

## 三、功能模块设计

### 3.1 后台管理（先做基础 HTML，后续可换 Vue/React 或合入现有后台）

1. **PGC 列表**
   - 分页表格：类型、标题、封面缩略图、集数、连载、状态、操作（编辑/删除/管理剧集）。
   - 筛选：类型、关键词、年份、地区、连载、状态（若后端支持）。

2. **创建 PGC**
   - 表单：类型、标题、封面 URL、简介、年份、地区、评分、是否连载。
   - 剧集：至少 1 集。每集：集数、标题、关联视频 ID(vid)、时长、发布时间。
   - 校验：vid 必须为站内已有视频 ID；创建接口一次提交「元数据 + 剧集列表」。

3. **编辑 PGC**
   - 仅可改元数据（标题、封面、简介、年份、地区、评分、连载）。  
   - 剧集增删走「添加剧集」「删除剧集」接口。

4. **剧集管理**
   - 在某个 PGC 详情下：列表展示当前剧集，支持「添加剧集」（集数、标题、vid、时长、发布时间）、「删除剧集」。

5. **发布/状态（可选扩展）**
   - 当前服务端创建即 `status=已通过`。若后续增加草稿：可新增「保存草稿」「提交审核」等接口与按钮，前端仅需调对应 API 并刷新状态。

### 3.2 C 端展示（后续 Flutter / H5）

- 列表：按类型 Tab（国创(CN)/日创(JP)/纪录片/电影/电视剧）、连载、推荐。
- 详情：封面、简介、年份/地区/评分、剧集列表；点击剧集跳转视频播放（vid）。
- 搜索：关键词 + 类型筛选。

## 四、接口与前端对应关系

| 前端能力     | 方法 | 接口路径 | 说明 |
|--------------|------|----------|------|
| 列表         | GET  | `/api/v1/pgc/list` | page, page_size, pgc_type, status, keyword, year, area, is_ongoing |
| 详情         | GET  | `/api/v1/pgc/detail?pgc_id=` | 单条详情 |
| 详情+剧集    | GET  | `/api/v1/pgc/detail-with-episodes?pgc_id=` | 详情 + 剧集列表 |
| 剧集列表     | GET  | `/api/v1/pgc/:pgc_id/episodes` | page, page_size |
| 创建         | POST | `/api/v1/pgc/create` | 需鉴权；body 见 CreatePGCReq |
| 更新         | PUT  | `/api/v1/pgc/update` | 需鉴权；body 见 UpdatePGCReq |
| 删除         | DELETE | `/api/v1/pgc/:pgc_id` | 需鉴权 |
| 添加剧集     | POST | `/api/v1/pgc/:pgc_id/episodes/add` | 需鉴权；body EpisodeReq |
| 删除剧集     | DELETE | `/api/v1/pgc/:pgc_id/episodes/:id` | 需鉴权 |
| 搜索         | GET  | `/api/v1/pgc/search` | keyword, pgc_type, page, page_size |
| 按类型       | GET  | `/api/v1/pgc/type/:type` | page, page_size |
| 连载         | GET  | `/api/v1/pgc/ongoing` | page, page_size |
| 推荐         | GET  | `/api/v1/pgc/recommended` | limit |

## 五、基础 HTML 范围（本期）

- **静态页**：由服务端提供 ` /admin/pgc.html`（或挂到现有静态目录），纯前端调用上述接口。
- **内容**：
  - 列表：分页 + 类型筛选 + 表格展示；每行操作「编辑」「删除」「管理剧集」。
  - 创建/编辑表单：元数据 + 剧集列表（创建时至少 1 集）；提交时带鉴权 Header（如 `Authorization: <token>`），token 可从输入框或登录页获取。
- **鉴权**：具备 PGC 权限的用户登录后，将 token 填入页面或本地存储，请求时携带，以便调用 create/update/delete/episodes 等需权接口。
